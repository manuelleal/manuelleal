# Engrama Lab

**An English and AI lab for language learning.**

I'm Christiam Puentes, an English teacher and PhD student in Education. I build tools for English classes, and I study how AI can help people learn languages where the connection is poor and the computers are old.

## Tools

| Tool | What it does | Where |
|---|---|---|
| **SET** | CEFR placement test with a result for each student and a view for the teacher. | [repo](https://github.com/manuelleal/SET) · [set.engramaingles.com](https://set.engramaingles.com/) |
| **Engrama** | Short daily English practice. The teacher rewards effort with coins and streaks. | [engramaingles.com](https://engramaingles.com/) |
| **EVA** | Live classroom quiz where accuracy wins, not speed. A wrong option is discarded and the student tries again. | [eva.engramaingles.com](https://eva.engramaingles.com/) |
| **Grader** | In development. It aims to grade paper exams from a phone photo, using machine learning and computer vision, with AI assistance to produce and to evaluate exams. | [repo](https://github.com/manuelleal/exam-grader) |

## Research

| Project | What it is |
|---|---|
| **[Echo](https://github.com/manuelleal/Echo)** | Offline English tutor for old school computers (2014 Celeron, 4 GB of RAM, no internet). Preregistered and blind-tested, with negative results reported. |
| **[Juaco](https://github.com/manuelleal/juaco)** | A minimal artificial organism that learns with local rules, without backpropagation. DOI: [10.5281/zenodo.23041088](https://doi.org/10.5281/zenodo.23041088) |
| **[juaco-metodo](https://github.com/manuelleal/juaco-metodo)** | The protocol I use to direct LLM agents in research: preregistration, planted errors, blind checks and a numbered error log. |

## Why

To narrow the gap in language learning in places with no good connection and no new equipment.
